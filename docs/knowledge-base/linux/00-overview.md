## was is Linux? (Simlified)

Linux is an operatin sytem that runs on most of the world/internets servers.
There are several diffrent distributions like e.g. ubuntu, debian, kali gentoo, or others.

One of the biggest advatages of a linux distrubution is that it is developed publicy (as open-soruce development)

### Why Linux?

Compared to windows, liux offers a more light-weight operatioing system base that is configurable to match the user needs.

Linux usually comes with the most important software already preinstalled, but unlike Windows linux systems often do NOT ship any bloatware.
